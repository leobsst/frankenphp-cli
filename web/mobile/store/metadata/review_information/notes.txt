FrankenManager is the companion app of FrankenManager, an open source tool (github.com/leobsst/frankenphp-cli) that runs a local PHP development environment on a computer. The app manages those computers ("instances") over HTTPS; it has no account and no server of its own.

To review the app, use its built-in demo mode (no instance, account or password needed):
1. Open the app and tap "Try the demo" on the first screen.
2. The dashboard of a simulated instance opens, with fictional projects and services. It runs entirely on the device: nothing is sent over the network.
3. Overview, projects, containers, logs, SSL, databases, Redis, S3, remote access and settings can all be browsed, and actions (add a project, switch PHP, stop or start the stack or a container, create a bucket...) run on the simulated data.
4. To leave the demo, open the menu and choose "Switch instance"; the Demo instance can be removed from the list (... > Remove from the app).

Pairing by QR code (the main way to connect in real use) needs the dashboard of a computer running FrankenManager: "Remote access" > "Pair a device" shows a one-time QR code that the app scans. The camera is used only for that scan. The demo shows that screen from the dashboard side ("Remote access" > "Pair a device").

The app collects no data: it only talks to the instances the user adds.
